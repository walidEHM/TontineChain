💡 1. Nom du projet (important pour le hackathon)

👉 Mon choix stratégique : TontiChain (clair + mémorisable)

🧠 2. Concept simplifié (à dire au jury)

"TontiChain est une plateforme basée sur la blockchain qui permet de créer des tontines sécurisées, transparentes et automatisées grâce aux smart contracts."

⚙️ 3. Fonctionnement (simple mais puissant)
Étape 1 : Création
Un utilisateur crée une tontine :
Montant (ex: 10 000 FCFA)
Fréquence (hebdomadaire)
Nombre de membres
Ordre des bénéficiaires

👉 Tout est stocké dans un smart contract

Étape 2 : Participation
Chaque membre :
Reçoit une invitation
Se connecte
Paye sa cotisation (Mobile Money ou crypto)
Étape 3 : Vérification
Tout le monde peut voir :
Qui a payé
Qui n’a pas payé
Montant total

👉 Transparence totale

Étape 4 : Paiement automatique
À la fin du cycle :
Le smart contract envoie automatiquement l’argent au bénéficiaire

👉 Pas d’organisateur = pas de fraude

🏗️ 4. Architecture technique (important pour toi dev)
🔹 Frontend
React / Next.js
UI simple (mobile-first)
Dashboard tontine
🔹 Backend
Node.js ou PHP (tu peux rester sur PHP si tu veux)
API pour gérer utilisateurs
🔹 Blockchain
Smart contract en Solidity
Réseau :
Polygon (moins cher)
ou Ethereum testnet
🔹 Paiement
Mobile Money (MTN / Moov) via API
Bridge vers crypto
🔐 5. Smart Contract (le cœur)

Il doit gérer :

Liste des membres
Montants payés
Tour actuel
Libération automatique

👉 Exemple logique :

if (tout_le_monde_a_paye) {
   envoyer_fonds(beneficiaire);
   passer_au_tour_suivant();
}
